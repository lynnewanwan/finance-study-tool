# 中级会计刷题诊断工具 v2.0

这是一个仅个人学习使用的浏览器刷题工具，当前支持：

- 中级会计 · 财务管理
- 中级会计 · 经济法

v2.0 在 v1 双科版基础上，加入 AI Question Intelligence Engine 的基础结构：知识库、题库状态、质量规则、AI 动态测试和错题订正规则。

## 核心功能

- 统一入口选择科目。
- 两科均支持“开始新一轮测试”“AI动态测试”“复习错题”。
- 两科均支持中断续答、手动结束、本地保存。
- 两科均支持标准答案解析和 AI 解题。
- 本地记录按科目隔离保存。
- 支持旧版财务管理记录自动/手动迁移。
- 支持导出当前科目学习记录。

## v2.0 学习逻辑

### 开始新一轮测试

- 30 题综合抽查。
- 按知识点尽量均衡覆盖。
- 排除当前错题集里的原题。
- 不打乱原题选项，尽量保留真题原貌。

### AI动态测试

- 30 题动态查缺补漏。
- 不包含当前错题集里的原题。
- 不包含在 AI动态测试里答错、且仍未订正的原题。
- 会根据错题所属知识点提高同类题出现概率。
- 同时兼顾未覆盖知识点和已掌握知识点保温。
- 选项会临时打乱，避免只记答案字母。

### 复习错题

- 专门处理当前错题集里的原题。
- 选项会临时打乱。
- 同一道错题连续答对 2 次后，从错题集中移出。
- 后续如果再次答错，会重新进入错题集。

## 题库构成

- 财务管理：71 道。
  - 2023-2025 本地真题单选题 51 道。
  - 2022 公开网页真题单选题 20 道。
- 经济法：66 道。
  - 2023-2025 本地真题单选题 66 道。

当前全库共 137 道题，均已通过 v2.0 基础质检。

## v2.0 数据文件

- `questions.json`：主题库。
- `questions-data.js`：浏览器本地加载题库。
- `knowledge-base.json`：双科知识库结构。
- `knowledge-base-data.js`：浏览器本地加载知识库。
- `quality-rules.json`：题库质量规则。
- `quality-rules-data.js`：浏览器本地加载质量规则。
- `generated-questions.json`：AI 生成题草稿结构。
- `generated-questions-data.js`：浏览器本地加载 AI 生成题草稿。

## AI 接口

前端优先调用 CloudBase AI 代理，Cloudflare Workers 作为 fallback。

当前 AI 解题已接入；AI 出题在 v2.0 中先完成数据结构和开发接口，为后续生成题入库做准备。

## 本地预览

进入本目录后运行本地静态服务，例如：

```bash
python3 -m http.server 8020
```

然后打开：

```text
http://localhost:8020/
```

开发者质检视图：

```text
http://localhost:8020/?dev=1
```

## GitHub Pages 发布

将本目录中的文件整体上传到 GitHub Pages 对应仓库根目录即可。

不要只上传 `index.html` 和 `app.js`，v2.0 还依赖多个数据文件。
