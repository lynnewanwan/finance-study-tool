# 中级会计刷题诊断工具 v3.0

这是一个仅个人学习使用的浏览器刷题工具，当前支持：

- 中级会计 · 财务管理
- 中级会计 · 经济法

v3.0 在 v2.0 双科与 AI动态测试基础上，正式扩展到三类客观题：单选题、多选题、判断题，并将两科现有资料中的可稳定解析客观题批量入库。

## 核心功能

- 统一入口选择科目。
- 两科均支持“开始新一轮测试”“AI动态测试”“复习错题”。
- 支持单选题、多选题、判断题。
- 支持中断续答、手动结束、本地保存。
- 支持标准答案解析和 AI 解题。
- 本地记录按科目隔离保存。
- 支持旧版财务管理记录自动/手动迁移。
- 支持导出当前科目学习记录。

## v3.0 学习逻辑

### 开始新一轮测试

- 30 题综合抽查。
- 按知识点尽量均衡覆盖。
- 排除当前错题集里的原题。
- 不按薄弱点加权，作为综合检测使用。

### AI动态测试

- 30 题动态查缺补漏。
- 不包含当前错题集里的原题。
- 不包含在 AI动态测试里答错、且仍未订正的原题。
- 根据错题所属知识点提高同类题出现概率。
- 同时兼顾未覆盖知识点和已掌握知识点保温。
- 题目最终打散，避免薄弱点/错题/未覆盖点/保温点集中出现。

### 复习错题

- 专门处理当前错题集里的原题。
- 选项会临时打乱。
- 同一道错题连续答对 2 次后，从错题集中移出。
- 后续如果再次答错，会重新进入错题集。

## v3.0 题型支持

- 单选题：选择 1 个选项后提交。
- 多选题：可选择多个选项，判分要求与正确答案完全一致。
- 判断题：统一使用 `A 错误`、`B 正确`。
- 结果页按题型展示本轮答对、答错和正确率。
- 多选题答错后会区分：你选对了、你错选了、漏选正确项。

## v3.0 数据文件

- `questions.json`：主题库。
- `questions-data.js`：浏览器本地加载题库。
- `knowledge-base.json`：双科知识库结构。
- `knowledge-base-data.js`：浏览器本地加载知识库。
- `quality-rules.json`：题库质量规则。
- `quality-rules-data.js`：浏览器本地加载质量规则。
- `generated-questions.json`：AI 生成题草稿结构。
- `generated-questions-data.js`：浏览器本地加载 AI 生成题草稿。

## AI 接口

前端优先调用 CloudBase AI 代理，Cloudflare Workers 作为 fallback。

v3.0 的 AI 解题请求已支持单选题、多选题和判断题；AI 例题 schema 增加 `exampleQuestionType`，可返回单选 / 多选 / 判断三类客观题例题。

## 本地预览

进入本目录后运行本地静态服务，例如：

```bash
python3 -m http.server 8031
```

然后打开：

```text
http://localhost:8031/
```

开发者质检视图：

```text
http://localhost:8031/?dev=1
```

## GitHub Pages 发布

将本目录中的文件整体上传到 GitHub Pages 对应仓库根目录即可。

不要只上传 `index.html` 和 `app.js`，v3.0 依赖多个数据文件。
