# 中级会计刷题诊断工具 v1 双科版

当前版本在 v1.3 财务管理基础上加入经济法，保持同一套浏览器本地学习架构。

## 功能

- 统一入口选择财务管理 / 经济法。
- 两科均支持 30 题摸底、薄弱点强化、错题复习。
- 两科均支持中断续答、手动结束、本地保存。
- 两科均支持标准答案解析和 AI 解题。
- 本地记录按科目隔离保存。
- AI 代理优先 CloudBase，保留 Cloudflare fallback。

## 题库

- 财务管理：2023-2025 本地真题单选题 51 道，另补 2022 公开网页真题单选题 20 道。
- 经济法：2023-2025 真题单选题清洗入库 66 道。
